# Zasoby Wspólne

Pliki, materiały i zasoby wykorzystywane w różnych klasach i lekcjach.

## Struktura katalogów

```
/obrazy/           # Grafiki, zdjęcia, ikony używane w lekcjach
/szablony/         # Szablony dokumentów, prezentacji
/przykłady/        # Przykładowe pliki do ćwiczeń
/narzędzia-online/ # Linki do narzędzi internetowych
/multimedia/       # Pliki audio, video
```

## Obrazy i grafiki

### Ikony systemowe
- Ikony aplikacji Linux Mint
- Symbole interfejsu użytkownika
- Piktogramy instruktażowe

### Materiały ilustracyjne
- Diagramy i schematy
- Zdjęcia sprzętu komputerowego
- Infografiki o bezpieczeństwie

## Szablony

### Dokumenty tekstowe (.odt)
- Szablon listu
- Szablon sprawozdania
- Szablon ulotki

### Prezentacje (.odp)
- Szablon prezentacji klasowej
- Szablon prezentacji projektowej

### Arkusze kalkulacyjne (.ods)
- Szablon budżetu domowego
- Szablon planu lekcji
- Szablon dzienniczka ocen

## Przykładowe pliki

### Do ćwiczeń formatowania tekstu
- Tekst bez formatowania do przepisania
- Dokumenty do korekty
- Materiały do łączenia dokumentów

### Do ćwiczeń z arkuszem kalkulacyjnym
- Dane do analizy (oceny uczniów, wydatki, statystyki)
- Tabele do stworzenia wykresów
- Bazy danych do ćwiczeń

## Wskazówki dotyczące praw autorskich

- Wszystkie materiały powinny być zgodne z prawem autorskim
- Preferowane licencje Creative Commons
- Przy wykorzystaniu materiałów zewnętrznych - zawsze podawać źródło
- Uczenie uczniów o prawach autorskich i licencjach
