# Dokumentacja Informatyki - Szkoła Podstawowa

Program lekcji informatyki dla klas 4-8 szkoły podstawowej, dostosowany do polskiej podstawy programowej i środowiska szkolnego.

## O projekcie

Ten projekt zawiera materiały dydaktyczne do nauczania informatyki w szkole podstawowej, przygotowane przez nauczyciela informatyki. Dokumentacja uwzględnia specyficzne potrzeby środowiska szkolnego oraz różnorodne potrzeby edukacyjne uczniów.

## Środowisko techniczne

- **Pracownia komputerowa**: Linux Mint 20.1 (LTSP)
- **Laptopy nauczycieli**: Windows 10 Pro + Entra ID
- **Monitorowanie**: epoptes
- **Licencje**: Microsoft A1

## Grupa docelowa

- **Uczniowie**: klasy 4-8 szkoły podstawowej
- **Uwzględnienie**: dzieci z orzeczeniem o specjalnych potrzebach edukacyjnych
- **Format**: 1 lekcja tygodniowo (45 minut)

## Podstawa programowa

Materiały realizują wymagania podstawy programowej dla informatyki w szkole podstawowej:
https://zpe.gov.pl/podstawa-programowa/szkola-podstawowa/informatyka

## 📋 Szczegółowy plan realizacji

**[Plan realizacji lekcji informatyki dla klas 4-8](plan-lekcji-klasy-4-8.md)** - kompleksowy dokument zawierający:
- Szczegółowe cele dla każdej klasy (4, 5, 6, 7, 8)
- 30-35 lekcji rocznie z dokładnym opisem tematów
- Metody nauczania dostosowane do wieku uczniów
- Narzędzia i oprogramowanie dla Linux Mint 20.1
- Integrację z Microsoft A1 (OneDrive, Teams)
- Dostosowania dla uczniów ze specjalnymi potrzebami edukacyjnymi
- Kompleksowy system oceniania
- Harmonogram implementacji
